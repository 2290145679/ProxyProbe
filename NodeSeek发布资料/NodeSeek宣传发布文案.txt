# [开源/自研] ProxyProbe：将 VPS 探针监控与多协议代理管理合二为一，Rust+Python 极致轻量仅占 100MB 内存！

> **前言**：  
> 相信不少 MJJ 手里都有十几台甚至几十台小鸡，平时为了看机器状态要装一套探针（哪吒 / ServerStatus），为了给小鸡配置节点又得装一套面板（3x-ui / x-ui），不仅要在各个后台来回切换、记一堆端口，还白白吃掉宝贵的内存。  
> 
> 为此，我开发了 **ProxyProbe** —— 一套将 **全景网络质量监控大盘** 与 **分布式多协议代理管理中枢** 深度融合的一站式系统。今天整理出来分享给大家，欢迎各位大佬把玩与交流！

---

## 🌟 核心特性与设计亮点

### 1. 🚀 极致轻量，512MB 玩具小鸡也能轻松起飞
- **Rust 原生高性能监控引擎**：核心探针由 Rust 编写，监控服务物理内存占用**仅不到 7MB**，节点采集端**仅占 1.5MB**！
- **整套全家桶常驻内存约 100MB**：包含代理管理中枢（Python 编译机器码）、Caddy 自动 SSL 网关与探针核心，即使在极低配的 512MB 内存机器上也能从容飞驰；
- **全项目磁盘仅占 110MB 左右**：轻装上阵，零臃肿依赖。

### 2. 🛡️ 全协议矩阵支持 & 中转落地任意编排
- 原生支持目前主流的抗封锁协议：
  - **VLESS Reality**（Xray 强劲驱动，原生支持 x25519 密钥、ShortID 与 SNI 伪装）
  - **Hysteria 2**（Sing-box 极速 UDP 协议，内置双向自签证书适配，丢包网络救星）
  - **Trojan**（内置 TLS 证书挂载与主流客户端强制握手兼容）
  - **Shadowsocks 2022**（`2022-blake3-aes-128-gcm`，严格保护 16 字节 PSK 密钥）
  - **VMess WS / VLESS WS / SOCKS5**
- **原生支持 Realm 端口中转与落地解密**：一台国内/中转鸡转发，远端海外鸡落地，后台一键图形化关联，自动生成对应客户端出站配置！

### 3. 📊 全景网络质量感知 & 三网延迟/丢包监控
- 直观展示每台 VPS 的 CPU、内存、硬盘、实时网络上下行速率与累计总流量；
- **真实三网网络质量监控**：支持配置电信、联通、移动的采样测试任务，直观查看毫秒级延迟与丢包柱状图；
- **全新自适应等宽网格**：手机端与电脑端完美自适应，告别标签错位折行。

### 4. 🔀 客户端路由分流规则中心 (内置四大预设)
- 支持对 **Clash / Clash Verge (YAML)** 与 **Sing-box (JSON)** 规则进行可视化定制；
- 开箱即用四大经典预设：
  - **国内外智能分流（推荐）**：局域网与国内直连，常见海外域名走代理，兼顾速度与隐私；
  - **极简轻量模式**：仅直连私有 IP 与中国顶级域名（.cn），其余默认走代理；
  - **全局代理模式**：除本地回环与局域网外，所有流量强制走代理节点；
  - **自定义专家模式**：完全放开控制权，随心定制规则列表；
- **快捷规则一键注入**：支持一键快捷追加常用 AI 规则（ChatGPT / Claude / Gemini）、常用外网（Google / YouTube / Telegram）与国内 IP 直连（GEOIP,CN）。

### 5. 📱 多客户端一键无感导入生态
- 提供通用聚合订阅 Token，支持一键无感导入：
  - **Clash / Clash Verge Rev**
  - **小火箭 (Shadowrocket)**
  - **Sing-box**
  - **v2rayN / Nekobox / Loon** 等；
- 提供虚拟流量信息节点（已用流量、剩余流量、到期倒计时），且内置测速保护（虚拟提示节点绝不会被放入 `url-test` 测速组造成超时红字）。

### 6. 📱 真正的 Mobile-First 移动端深度适配 & 双主题
- 针对手机竖屏视口（360px~430px）进行深度响应式重构，杜绝任何页面左右横向滑动；
- 支持 **沉稳黑白经典** 与 **浪漫樱花粉** 双套主题一键无缝切换，主题配置跟随账号持久化保存。

### 7. 🤖 Telegram 双向运维机器人 & 数据一键快照备份
- 支持 Telegram Bot 双向交互运维，通过手机即可发送运维指令：
  - `/status`：查看全网节点状态与流量简报
  - `/test`：触发全网节点真实端到端协议握手测速
  - `/backup`：一键触发 SQLite 核心数据库快照并自动打包推送至手机
  - `/nodes`：快速列出各节点健康度
- **纯业务数据解耦备份**：导出的备份包为纯 SQLite 数据快照，重装系统后一秒恢复所有机器、节点与用户数据！

## 💻 快速安装体验

### 主控端（面板服务器）一键部署：
推荐使用全新干净的 Debian 11/12/13 或 Ubuntu 20.04/22.04 系统：
```bash
# 执行主控端一键安装脚本（Caddy 自动申请 SSL 并启用 HTTP/3）
curl -fsSL https://raw.githubusercontent.com/2290145679/ProxyProbe/main/scripts/deploy-hub.sh -o deploy.sh && bash deploy.sh
```

### 终端交互控制台 (hhub)：
安装完成后，在终端敲 `hhub` 即可调出交互式管理控制台，支持快捷改密、改端口、备份还原、查看日志与一键无损在线热升级。
