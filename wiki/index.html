🌟 核心设计两大亮点

ProxyProbe 从底层架构设计之初便紧紧围绕“极简自动化运维”与“高可用商业化闭环”两大核心诉求，彻底颠覆传统多面板拼凑、配置复杂、统计失真与单点故障的运维困局。

亮点一：分布式全景探针感知与全协议自动化流控一体化

• 一键全家桶全协议生成：在目标服务器上一键批量拉起 AnyTLS、Hysteria 2、TUIC v5、VLESS Reality、VMess-WS、Trojan、Shadowsocks 等全套现代协议，智能避让端口并自动签发证书秘钥，0 门槛秒建节点。
• 全景矩阵与感叹号透视：主控端与探针核心采用 Rust 编写，探针内存占用低于 15MB；大盘异常感叹号一键点击直达故障节点与日志，支持自主调节巡检周期。
• 自适应智能聚合订阅：单一订阅链接依据客户端 User-Agent 智能下发对应规则，内置 Clash / Sing-box 分流规则可视化中心与国家地区国旗 Emoji 自动解析。

亮点二：极致开箱即用与商业化运营全流程闭环

• 极速一键部署与 hhub 终端控制台：一行命令自动化完成主控安装、SSL 证书自动签发、Caddy 统一反代网关与守护进程配置；内置 hhub 控制台随时无损切换域名/IP。
• VIP 等级物理隔离与配额控制：低等级用户物理级无感高等级独立专线，抗封锁且保护高净值资产；套餐支持自由二次编辑。
• Telegram 双向运维与自动热备份：TG 机器人支持双向交互命令（/status, /test, /backup, /nodes），定时将 SQLite 数据库打包 Gzip 推送至私聊；支持全站公告、弹窗通知、客户端直链分发与 SMTP 邮箱验证注册。

🚀 极速一键安装与被控节点秒级接入

无需手动编译、无需繁琐配置 Nginx/Caddyfile，ProxyProbe 提供了全自动的安装流水线，5 分钟内即可拥有一整套高可用管控中心。

1. 主控端一键极速部署（全新服务器推荐）

推荐操作系统：Ubuntu 22.04+ / Debian 11+（需开放 80、443 端口）：

BASH - 交互式极速部署 
curl -fsSL https://raw.githubusercontent.com/2290145679/ProxyProbe-Release/main/deploy-hub.sh | bash

执行后脚本将以交互方式引导您完成极简配置：

  • 📌 绑定域名或公网 IP：输入已解析域名将由 Caddy 自动申请免费 SSL 证书；输入 IP 则开启纯 IP 模式；
  • 🔑 管理员初始密码：可自定义输入，留空将自动生成高强度安全随机密码；
  • 🌐 访问端口与通信：脚本全自动配置 systemd 守护进程、安全防火墙策略与 hhub 控制台工具。
BASH - 非交互静默部署（自动化装机专用） 
export DOMAIN=tz.yourdomain.com ADMIN_PASS=MyStrongPassword2026
curl -fsSL https://raw.githubusercontent.com/2290145679/ProxyProbe-Release/main/deploy-hub.sh | bash

2. 被控探针节点 (Agent) 秒级接入

在管理后台【服务器】界面点击“添加服务器”，系统将为您生成该机器专属带有安全通信 TOKEN 的单行 Shell 指令。在任意远端 Linux 服务器终端粘贴并回车：

BASH - 探针节点接入指令示例 
curl -fsSL https://tz.yourdomain.com/proxy-agent.sh | bash -s -- --token YOUR_SERVER_TOKEN

💡 自动化流程：脚本自动部署轻量级 monitor-agent、按需准备 Xray-core / Sing-box / Realm 引擎、签发 ECC 证书，并启动 5 秒级热同步守护进程。

⚡ 一键全家桶协议创建与极速生成

针对日常运维中一台服务器需要部署多个协议的繁琐操作，ProxyProbe 创新研发了“一键全家桶协议创建”引擎。

什么是「一键全家桶」？
管理员在【代理协议】界面仅需选择目标服务器并点击「一键生成全家桶」，系统将自动完成全套协议规划：
• 自动规划并分配多个互不冲突的高速端口；
• 一次性为该服务器批量配置 AnyTLS、Hysteria 2、TUIC v5、VLESS Reality (Vision/XHTTP)、Trojan、VMess-WS、Shadowsocks 2022；
• 自动生成 x25519 秘钥对、安全 UUID、连接密码与大厂真实 SNI 伪装域名（如 Apple / Yahoo）；
• 5 秒内全网同步生效，并立即加入到全自适应客户端订阅链中。

协议参数极简降噪 (Decluttered Modal)

单独添加节点时，弹窗默认仅展现必填项（服务器、协议类型、节点名称、监听端口）。高阶复杂的伪装头部、Path、PublicKey 等全量自动安全预填并收拢在「高级配置」中，普通运维开箱即用，资深专家随时展开微调。

🔀 自适应智能聚合订阅与可视化分流规则中心

1. 单一订阅链接全客户端自适应

用户无需纠结复制哪种格式的订阅。单一订阅 URL 后端根据客户端的 User-Agent 自动分发最优配置：

  • ⚡ Clash / Clash Verge / Mihomo ➜ 自动分发预设分组与规则完整的 Clash YAML 配置；
  • ⚡ Sing-box 官方客户端 ➜ 自动分发原生 JSON 路由规则配置；
  • ⚡ Shadowrocket / v2rayN / Quantumult X ➜ 自动分发标准 Base64 聚合节点链；
  • ⚡ 支持强制参数：添加 ?clash=1、?singbox=1、?b64=1 可手动覆盖。

2. 客户端分流规则中心 (`/admin/rules`)

后台内置可视化的规则中心，预置四大经典分流策略：「国内外智能分流 (默认推荐)」、「极简轻量」、「全局代理」、「自定义专家」。支持对规则组进行语法高亮编辑、注入自定义拦截标签，并在管理界面实时预览客户端完整配置。

3. 节点国家地区国旗 Emoji 智能识别

节点管理与订阅分发引擎会根据节点所在地理位置代码（如 HK、JP、US、SG 等）或名称关键字，自动前置匹配对应国家地区国旗 Emoji（🇭🇰/🇯🇵/🇺🇸/🇸🇬/🇨🇳/🇩🇪 等），全平台客户端展示清爽统一。

🚨 节点全景感知、异常诊断与巡检控制

1. 健康度异常感叹号一键透视

当主控大盘检测到节点出现离线或握手失败时，卡片顶部的健康度感叹号 (!) 与 (X 个异常) 徽章支持直接交互点击，弹出全屏诊断浮窗，直观列出所有故障节点名称、协议类型、归属服务器及具体报错日志，并支持一键发起即时重测。

2. 后台静默自动巡检周期自定义

支持在连通性矩阵界面通过下拉菜单调节后台巡检间隔（1 分钟、3 分钟、5 分钟、10 分钟、15 分钟、30 分钟、60 分钟），参数动态持久化并在后台线程自适应生效，不再硬编码固定周期。

3. 流媒体与主流 AI 平台解锁深度检测

针对各大节点提供全自动流媒体解锁探测（Netflix 原生解锁、Disney+、YouTube Premium）与主流 AI 矩阵（OpenAI / ChatGPT、Anthropic Claude、Google Gemini）检测。默认保持关闭以节约服务器资源，有需要可随时一键开启。

📶 三网骨干网络延迟监控任务 (`/admin/ping`)

ProxyProbe 内置多维度的真实网络质量感知体系。在【延迟】管理页面中，可添加自定义 Ping 监控任务（如针对广东移动 BGP 优选、广东联通高速直连、广东电信骨干网的指定 IP 与端口）。

各被控节点在后台独立发起实际的 TCP 建连与 TLS 握手测试，毫秒级上报历史延迟数据与可用率指标，帮助管理员第一眼识别线路波动或运营商网络劣化。

📦 Telegram 定时自动备份与数据维护 (`/admin/data`)

数据是业务运转的核心命脉。ProxyProbe 提供了全方位的数据安全保障：

1. Telegram 定时自动推送备份

在数据维护界面中开启“Telegram 机器人定时自动备份”，可自由设置备份周期（如每 24 小时）。系统将自动在后台进行 SQLite 在线热备份（Online Backup API），经 Gzip 压缩后直接发送至管理员 Telegram 私聊，彻底解决单点损坏或机房故障隐患。

2. 数据维护大盘与一键空间回收 (VACUUM)

直观展现当前数据库文件大小、预写日志 (WAL) 大小、可回收磁盘空间、数据保留天数及历史明细行数。支持一键点击「立即回收」清理冗余空间，支持「导出备份」下载原始数据库文件，支持直接上传历史 .db 或 .db.gz 镜像包一键恢复。

❓ 常见问题排查与运维指南 (FAQ)

Q1: 新建了 Hysteria 2 节点却测试连接超时？

1. 检查核心安装状态：在节点列表所属服务器旁确认 Sing-box 指示灯是否为绿色；
2. UDP 端口放行：Hysteria 2 基于 UDP 传输，请务必在服务器安全组与系统防火墙（如 ufw allow 端口/udp）放行该 UDP 端口。

Q2: 刚安装时使用的是公网 IP，后面域名解析好了如何切换为 HTTPS？

无需重新安装！在主控终端输入 hhub，选择 [7] 修改绑定域名/IP，直接输入您解析好的新域名。脚本将自动调整端口至 443、通过 Caddy 自动申请免费 SSL 证书，全站所有用户的聚合订阅链接也将自动适配为最新域名！

Q3: 新版本发布后，如何进行无损升级？

方式一：直接在管理后台右上角点击跳动的版本更新徽章，在弹窗中点击「一键无损热升级」；
方式二：在终端输入 hhub，选择 [9] 一键无损热升级系统。所有数据库数据与节点配置均 100% 完整保留。

Q4: 如何查看主控中枢的后台实时运行日志？

在 Linux 终端执行以下指令即可查看实时日志：

BASH
systemctl status proxy-manager.service --no-pager
journalctl -u proxy-manager.service -f
